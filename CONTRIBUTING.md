# Contributing to Shajjra (شجرہ)

Thank you for your interest in contributing to the **Shajjra Genealogical Archive & Specification**.

This repository is dedicated to preserving historical, ancestral, and familial lineages (*Shajra-e-Nasab*) across South Asian, Middle Eastern, and Islamic heritage traditions, as well as maintaining open data specifications for pedigree chart visualization.

---

## 📜 Principles & Privacy Standards

Before submitting genealogical data or pull requests, please note:

1. **Strict Privacy for Living Individuals:**
   - **Do NOT** submit phone numbers, email addresses, national ID / social security numbers, or exact residential addresses.
   - For living individuals, only public genealogical relationships (Name, Patrilineal link, Gender, Clan identifier) should be included.
2. **Historical Accuracy & Documentation:**
   - Where possible, cite verifiable historical, biographical, or oral tradition sources for classical ancestors (Generations 1–30).
3. **Open Schema Compliance:**
   - All dataset submissions must validate against [`schema/shajjra-node.schema.json`](schema/shajjra-node.schema.json).

---

## 🛠️ How to Contribute

### 1. Submitting Lineage Corrections or Expansions
- Open a GitHub Issue using the **Lineage Correction** template.
- Specify the ancestral node name, approximate generation, father/mother IDs, and supporting family notes.
- You can also reference the live platform at [shajjra.com](https://shajjra.com).

### 2. Improving Documentation & Guides
- Guides in the [`guides/`](guides/) directory accept contributions regarding:
  - Complex consanguinity algorithms.
  - Historical migration patterns (e.g. Arab tribes settling in Sindh, Punjab, Balochistan).
  - Graph visualization techniques in SVG and HTML Canvas.

### 3. Open Spec & Tree CSS
- Contributions to [`assets/tree-modern.css`](assets/tree-modern.css) (supporting dark mode, vertical compact layouts, and mobile zoom) are warmly welcomed via Pull Request.

---

## 🤝 Code of Conduct

Please engage with respect, patience, and academic rigor. Family history is personal and deeply cultural. All contributors are expected to uphold constructive collaboration.

For questions, visit [shajjra.com](https://shajjra.com) or reach out to [Naveed Kumbhar](https://naveedkumbhar.com).
